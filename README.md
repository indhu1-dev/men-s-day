# Men's Day Fastest Finger Challenge

A no-build, static quiz for International Men's Day 2026. It uses the supplied questions, gives 10 points for a correct answer, and records one elapsed time for the complete round. Faster overall rounds break score ties. There is no per-question deadline.

## Run locally

Open `index.html` in a browser, or use any static file server. For example, from this folder:

```powershell
npx --yes serve .
```

The icon and typeface use CDNs; the QR code is generated by QRServer after a deployed URL is available.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
3. The included workflow deploys on each push. When the workflow completes, open **Settings → Pages** to get the published URL.
4. Open the published site and select **Event flyer**. The quiz link and QR code automatically use the published URL. The event time is left as "To be announced."

## Leaderboard

Scores and names are saved in the participant's browser using local storage. This static site does not send participant data to a server, so each device has its own leaderboard. To rank participants across devices, connect a shared database/service.

## Questions

Question text, options, and correct answers live in `questions.js` and can be edited before publishing. The UPS milestone question uses the provided answer key.
