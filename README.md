# Men's Day Fastest Finger Challenge

A static GitHub Pages quiz backed by Supabase for shared results. Participants provide a name and UPS ID, continue to a ready screen, and start the clock only by pressing **Start Quiz**. The server records the start time, scores the submitted answers, allows one attempt per UPS ID, and ranks by score descending then total time ascending. The public leaderboard is limited to ten entries and masks UPS IDs.

## Configure shared results

Create a Supabase project for the event. In its SQL Editor, run `supabase/schema.sql`. Install the Supabase CLI, log in, link the project, and deploy the Edge Function:

```powershell
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase functions deploy quiz-results
```

Set the project URL and public anon key in `config.js`:

```js
export const SUPABASE_URL = 'https://YOUR_PROJECT_REF.supabase.co';
export const SUPABASE_ANON_KEY = 'YOUR_PUBLIC_ANON_KEY';
```

The anon key is intended for browser use. Never put the Supabase service-role key in this repository or `config.js`; the Edge Function uses the server-side `SUPABASE_SERVICE_ROLE_KEY` environment secret. The database table denies direct access to browser roles.

The Edge Function keeps the answer key server-side. The public `questions.js` contains only question text and options. UPS IDs are stored in the private results table; the public top ten shows only a masked ID and display name. UPS ID format is checked, but employment/ID ownership is not verified against an internal UPS directory. Add an approved identity provider or internal verification before treating an ID as proof of identity.

## Publish with GitHub Pages

1. Configure Supabase and `config.js` first.
2. Push the project to the `feature/mens_quiz` branch (the workflow also supports `main` and `master`).
3. In the GitHub repository, open **Settings → Pages** and select **GitHub Actions** as the source.
4. After the workflow completes, open the Pages URL. The **Event flyer** link and QR code use the published site URL automatically.

The flyer date is November 19, 2026; event time remains “To be announced.”

## Run locally

Open `index.html` through a local static server. Browser modules and Supabase requests are not supported reliably from a `file://` URL. The icon and font are loaded from CDNs; QR images are generated by QRServer once published.

## Questions and ranking

Question text and options are in `questions.js`. The Edge Function answer key must be updated in `supabase/functions/quiz-results/index.ts` whenever the question order or correct answers change. A participant can submit once per UPS ID. Tied scores are ordered by server-recorded total time, then submission timestamp.
